# 問題のエクスポート・インポート

「問題」タブの「問題のエクスポート・インポート」から、JSON・CSVで問題をまとめて追加できます。ログイン中は自分のアカウントに同期され、Firebase未設定時はこのブラウザ内に保存されます。

## 問題を増やす

1. 「CSVテンプレート」または「JSONテンプレート」をダウンロードします。取り込めるオリジナル問題が1問入っています。
2. テンプレートを編集して問題を増やします。新規問題のIDは空欄にできます。CSVをExcelで編集する場合は「CSV UTF-8」で保存します。
3. ファイルを選択すると、追加・更新・スキップの件数と先頭5問が表示されます。JSONは直接貼り付けても確認できます。
4. 内容を確認し、「確認して取り込む」を押します。ファイルを選ぶだけでは保存されません。

同じIDの問題は初期設定ではスキップします。既存問題を編集する場合だけ「同じIDの問題を更新する」を選んでください。内蔵問題も更新でき、非表示設定も反映します。正答率・回答履歴は同じIDに引き継がれます。

IDが違っていても、テーマ・問題文・4つの選択肢・正解・解説がすべて同じ新規問題は重複追加しません。同じファイルを再度取り込む場合にも使えます。非表示の既存問題と同じ内容を取り込むだけでは再表示しません。既存問題の表示設定を変更するか、同じIDの更新を使用してください。ファイルにない既存問題は削除されません。

## 問題を書き出す

「すべての問題」または「検索・テーマで絞り込んだ問題」を選び、「JSONを書き出す」「CSVを書き出す」を押します。内蔵問題・追加問題・編集済み問題・非表示の問題が対象です。学習ログ、正答率、設定などは含みません。

別の端末やアカウントへ問題だけを移す場合や、編集前のバックアップにはJSONが便利です。表計算ソフトで問題を増やす場合にはCSVが使えます。

## CSV形式

文字コードはUTF-8です。エクスポートは日本語版Excelで開けるBOM付きです。列の順番は変更できますが、以下の10列をすべて含めてください。

| 列名 | 内容 |
|---|---|
| ID | 既存問題を更新する場合は同じID。新規問題は空欄で自動採番 |
| テーマ | アプリのテーマ名またはキー。例：`auth` |
| 問題文 | 空欄不可 |
| 選択肢ア、選択肢イ、選択肢ウ、選択肢エ | 4列とも必須。同じ選択肢は不可 |
| 正解 | `ア`〜`エ`、または `1`〜`4` |
| 解説 | 空欄不可 |
| 非表示 | `true`で非表示。`false`または空欄で表示 |

カンマ・引用符・改行を含むセルにも対応します。CSVのエクスポートでは数式として解釈される文字列の先頭に `'` を付け、このアプリで再読込した際に復元します。書き出されたセルの先頭の `'` はそのままにしてください。

## JSON形式

エクスポートは次の構造です。`questions`の配列だけのJSONでも取り込めます。`a`はCSVと異なり**0始まり**です。

```json
{
  "format": "sc-study-questions",
  "version": 1,
  "questions": [
    {
      "id": "",
      "t": "auth",
      "q": "多要素認証の組み合わせとして適切なものはどれか。",
      "c": ["パスワードと秘密の質問", "パスワードと認証アプリのワンタイムコード", "暗証番号とパスワード", "秘密の質問を2つ"],
      "a": 1,
      "e": "知識情報と所持情報という異なる種類の要素を組み合わせます。",
      "hidden": false
    }
  ]
}
```

`id`は省略・空欄で自動採番します。指定する場合は128文字以内の半角英数字・ハイフン・アンダースコアです。`__proto__`、`constructor`、`prototype`は使えません。同じファイル内のID重複はエラーです。`hidden`は省略可能で、初期値は`false`です。

テーマは「使えるテーマ一覧」で確認できます。未知のテーマは取り込めません。問題文・解説・選択肢の前後の空白は取り込み時に除きます。

## 上限とエラー

- 一度の取り込みは5MB・5,000問までです。問題文は2万字、解説は5万字、各選択肢は1万字までです。
- 不正な問題があるとファイル全体の取り込みを止め、問題の位置と理由を表示します。修正して再度選んでください。
- ブラウザの保存容量が足りない場合は、既存データを維持してエラーを表示します。
- ログイン中は400問ずつ保存します。途中で失敗した場合は確定済みの件数を表示します。再確認して取り込むと、保存済みの同じ内容はスキップされます。
- 通信が切れた場合は、通信復帰後に保存が続きます。「保存しました」が表示されるまで画面を開いてお待ちください。

自作問題など、利用できる問題を取り込んでください。IPA過去問題の利用条件と、非公開の試験問題を扱わない方針はREADMEのとおりです。
